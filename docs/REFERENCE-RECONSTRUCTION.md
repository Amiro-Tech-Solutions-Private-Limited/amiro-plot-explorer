# Reference-based 3D interiors

The interactive viewer remains the default. The developer image gallery is available as
a visual reference; it is not presented as a navigable 3D capture.

The North Park theme uses independently authored meshes for the sofa, curved armchair,
layered bedding, folded curtains, basin and wall-hung WC. Scanned supporting assets add
leaf detail and material normal/roughness maps. Detailed assets are loaded for the
currently visited full-height home; neighbouring homes and the floor overview retain
lighter geometry. Removed or replaced design features are respected. Walking collision
footprints stay tied to the furniture layout.

The source images show only one camera angle per room. The model therefore approximates
the unseen sides, room dimensions, furniture construction and lighting. It is not the
developer's original architectural model and should not be sold as an exact digital twin.
An exact match requires the developer's original scene/CAD/BIM plus verified floor plans,
or a measured photogrammetry/LiDAR capture.

Asset provenance and rebuild instructions are in `public/showhome/SOURCES.md`.
